# v0.4.0 UI 검증

Chrome의 실제 브라우저 렌더링을 고정 크기 iframe에서 검증했습니다. 실제 Android 기기의 터치 지연, 브라우저 주소창, 확대 접근성은 별도 확인이 필요합니다. 테스트 fixture HTML은 임시 dist에만 만들고, 최종 build에서 제거합니다.

| CSS 뷰포트 | 손패 | 문서 크기 | 손패 가로 경계 | 손패 아래 / 조작줄 위 | 제출 버튼 아래 |
|---|---:|---|---|---|---:|
|390×780|10장|390×780|13.9~376.1|716.2 / 723|775.5|
|360×640|10장|360×640|22.6~337.4|583.3 / 589|638.5|
|844×390|10장|844×390|95.2~748.8|339.8 / 349|389.5|
|1024×768|10장|1024×768|112.2~911.8|693.7 / 709|764.5|
|390×780, 8인|8장|390×780|14.7~375.3|714.8 / 723|775.5|

모든 경우 페이지 가로/세로 스크롤이 없고 손패와 조작 버튼이 화면 안에 있습니다. 360×640에서 10장 입찰 선택지 0~10이 든 양피지의 세로 경계는 145.2~389.0이며 손패와 겹치지 않습니다.

실제 UI에서 새 연습 시작, 대기실, 입찰, 카드 선택, 버튼 제출, 마우스 포인터로 위로 밀기 제출, AI 응답, 라운드 결과를 확인했습니다. 10장 테스트에서 지도 3을 위로 밀어 내자 손패가 10장에서 9장으로 줄고 4장 트릭이 판정되었습니다.

다음은 게임 엔진/서버 자동 테스트로 별도 검증합니다: 모든 규칙 시나리오, 비공개 카드/입찰, 권한, 재접속, 중복 명령, 100개 시드의 전체 게임, 정적 파일/캐시 분리. UI 변경은 게임 엔진·서버 동작을 변경하지 않습니다.
